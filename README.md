# STORM ADDRESSES

## **О проекте**
STORM ADDRESSES — специализированный инструмент для поиска, валидации, структурирования и нормализации адресных данных, геолокационных меток и пространственных координат. Приложение предоставляет удобный графический интерфейс для пакетной проверки адресов, геокодирования, выявления дубликатов и экспорта структурированной информации в форматы JSON, CSV и GeoJSON.

## **Происхождение и форки**
Проект является оригинальной разработкой ReiKatari в рамках экосистемы STORM SOFT. Все алгоритмы валидации и модули интеграции с картографическими сервисами созданы с нуля.

## **Технологический стек**
- **Языки программирования**: TypeScript, JavaScript (Node.js 20+)
- **Пользовательский интерфейс**: React 18, Tailwind CSS, Lucide Icons, Vite
- **Гео-библиотеки и картография**: Leaflet, OpenStreetMap API, Nominatim Geo Engine, Turf.js
- **Сборка и упаковка**: Vite, PostCSS, Electron
- **Управление состоянием и хранение**: Zustand, IndexedDB, LocalStorage

## **Ключевые возможности**
- **Интеллектуальный поиск и автодополнение**: Мгновенный поиск адресов с исправлением опечаток и подсказками на лету.
- **Пакетная нормализация данных**: Обработка списков из тысяч адресов с приведением к государственным и международным стандартам.
- **Интерактивная карта**: Отображение найденных объектов, полигонов районов и расчет расстояний между точками.
- **Прямое и обратное геокодирование**: Преобразование координат (широта/долгота) в читаемый адрес и наоборот.
- **Экспорт и интеграции**: Выгрузка отчетов в форматах CSV, Excel, GeoJSON, KML и интеграция с внешними API.

## **Поддерживаемые платформы и эмуляторы**
- **Операционные системы**: Windows 10/11 (x64, ARM64), Linux (Ubuntu, Debian, Arch), macOS (Apple Silicon / Intel)
- **Веб-окружение**: Современные браузеры с поддержкой WebAssembly и WebGL (Chromium, Firefox, Safari)
- **Интеграция с картами**: OpenStreetMap, Mapbox, Яндекс Карты (Tile Layer)

## **Установка и запуск**
1. Перейдите на страницу **Releases** репозитория на GitHub.
2. Скачайте актуальный установщик или архив с программой.
3. Запустите инсталлятор и следуйте инструкциям мастера установки.
4. Для запуска портативной версии распакуйте архив в любую удобную директорию и запустите исполняемый файл.

## **Безопасность и цифровые подписи**
Все исполняемые файлы и дистрибутивы подписаны доверенным цифровым сертификатом разработчика **CN=STORM SOFT, O=STORM EDEN** с криптографическим хэшем SHA-256 (DigiCert / Authenticode). Это гарантирует неизменность бинарных файлов и отсутствие вредоносного кода. При появлении предупреждения Windows SmartScreen выберите «Подробнее» → «Выполнить в любом случае» либо установите корневой сертификат разработчика в хранилище «Доверенные корневые центры сертификации».
